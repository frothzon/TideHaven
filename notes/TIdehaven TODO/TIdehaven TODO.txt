Tidehaven update baseline

This is a static code inventory, not a completed gameplay walkthrough. Git baseline: acdc53c.

Already present in the project
- Health and energy bars are drawn. Tool actions consume stamina and stamina regenerates.
- XP, level-ups, skill points, and a skill tree are implemented in code; they need integrated playthrough checks.
- Inventory, equipment, recipe tabs, and a minimap exist. The unified menu state is implemented: P opens inventory, M opens the world map, B opens skills, and Escape returns to gameplay. The views are exclusive and pause gameplay.
- The Perlin world, resource/enemy spawning, and basic wall/floor/soil construction are present.
- The generated cave/shrine route runs as an in-room scene. An isolated runtime scenario now verifies entry, an unobstructed wall corridor, the one-time shrine reward, and return to the saved overworld position; a keyboard playthrough remains useful.
- Fish exists as a healing item, but the current code has no fishing interaction.
- Versioned JSON save/load and legacy progression migration are implemented. An isolated runtime scenario verifies representative legacy migration and field-by-field reload for progression, skills, seed, inventory, shrine state, player position, templates, and room snapshots. A real legacy user save and plant-growth persistence still need checks.
